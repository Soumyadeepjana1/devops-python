The range() function in Python is used to generate a sequence of numbers. It is commonly used in for loops to repeat an action a specific number of times.

Syntax
range(start, stop, step)
start (optional): The first number in the sequence. Default is 0.
stop (required): The sequence stops before this number.
step (optional): The difference between consecutive numbers. Default is 1.
1. range(stop)

Starts from 0.

for i in range(5):
    print(i)

Output:

0
1
2
3
4
2. range(start, stop)
for i in range(2, 6):
    print(i)

Output:

2
3
4
5
3. range(start, stop, step)
for i in range(1, 10, 2):
    print(i)

Output:

1
3
5
7
9
Negative Step (Counting Backwards)
for i in range(10, 0, -2):
    print(i)

Output:

10
8
6
4
2
Converting range to a List
numbers = list(range(5))
print(numbers)

Output:

[0, 1, 2, 3, 4]
Practical Examples
Print numbers 1 to 10
for i in range(1, 11):
    print(i)
Print even numbers from 2 to 20
for i in range(2, 21, 2):
    print(i)
Print a message 5 times
for i in range(5):
    print("Hello")
Sum numbers from 1 to 100
total = 0

for i in range(1, 101):
    total += i

print(total)

Output:

5050
Important Points
The stop value is not included.
range() returns a range object, not a list.
Use list(range(...)) if you need an actual list.
A negative step is used to count backwards.
Quick Summary
Code	Output
range(5)	0 1 2 3 4
range(2, 6)	2 3 4 5
range(1, 10, 2)	1 3 5 7 9
range(10, 0, -2)	10 8 6 4 2

range() is one of the most frequently used functions in Python because it makes it easy to iterate over a sequence of numbers efficiently.
